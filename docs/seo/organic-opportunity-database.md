## Decision rules

- UPDATE: Improve an existing page with demonstrated search visibility or meaningful conversion potential.
- MERGE: Consolidate only where query/page evidence confirms the same search intent. Preserve the strongest URL and map redirects only after review.
- CREATE: Add a page only for a distinct, evidenced search need not adequately served by an existing URL.
- BUILD: Prefer a genuinely useful calculator, template, or interactive resource when it solves the searcher's task better than another article.
- ACQUIRE: Earn links through original research, expert contributions, useful resources, and legitimate partnerships.
- MEASURE: Track organic registrations and first meaningful accounting actions, not rankings or impressions alone.

## Data notes

- Search Console's query report omits some anonymized searches. Query totals are not expected to equal page totals.
- The property returned 53 page records and 116 query records in the 28-day query-only pull. The query+page pull returned 130 rows because URLs and query combinations create multiple records.
- Page-level figures are aggregated by Google; averages and CTR can differ when dimensions are combined.
- Search volume, keyword difficulty, backlinks, competitor URLs, and organic-attributed registrations are not yet available in this snapshot.
- A country is only recorded at the aggregate country report level. Do not assign a country to an individual query unless a country-filtered query report is retrieved.
- Non-canonical host variants appeared for some pages. Verify canonical consolidation separately; do not assume every variant is a separate page opportunity.
- Rankings are average positions, not fixed positions for every user or search.

## Weekly review template

For each opportunity, record:
- Reporting window and extraction date
- Query and country
- Clicks, impressions, CTR, and average position
- Landing URL and canonical URL
- Search intent and competitor URLs
- Changes shipped and deployment date
- Organic sessions and landing-page engagement
- Signup starts and completed registrations
- First invoice, first expense, and first report events
- Activated organic users and returning users
- Decision: expand, update, consolidate, build, acquire, or discontinue
